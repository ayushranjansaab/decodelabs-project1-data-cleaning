# DecodeLabs Project 1 — Data Cleaning & Preparation

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship.

The objective of this project was to clean and prepare the provided dataset for further data analysis by identifying missing values, checking duplicates, and standardizing data formats.

## Data Cleaning Performed

- Checked and handled missing values.
- Replaced missing CouponCode values with `NO COUPON`.
- Checked OrderID values for duplicates.
- Checked complete rows for duplicate records.
- Standardized Date format to `YYYY-MM-DD`.
- Standardized Quantity as whole numbers.
- Standardized ItemsInCart as whole numbers.
- Standardized UnitPrice to 2 decimal places.
- Standardized TotalPrice to 2 decimal places.
- Verified CustomerID, TrackingNumber, PaymentMethod, OrderStatus, and ReferralSource.
- Created a Cleaning Log to document the changes.

## Final Verification

- Missing values: 0 blanks found in the final cleaned data.
- Duplicate OrderIDs: 0 duplicates found.
- Duplicate complete rows: No duplicate values found.
- Date format: Standardized and verified.
- Numeric formats: Checked and standardized.
